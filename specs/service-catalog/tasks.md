# service-catalog — Implementation Plan (tasks)

**Goal:** service catalog CRUD for the workshop manager: `POST/GET/PATCH/DELETE
/api/v1/services`, all JWT-protected, with logical deletion and an active/inactive flag.

**Architecture:** vertical slice `internal/features/servicecatalog/` (handler → service →
repository → model), reusing `internal/shared/{database,httpx,middleware}`; `cmd/api/main.go`
only wires and registers routes. See [design.md](design.md).

**Tech Stack:** Go 1.22 stdlib `net/http` (method patterns + `PathValue`),
`github.com/jackc/pgx/v5` (already pinned), PostgreSQL 16. No new dependency.

## Global Constraints

- Go 1.22 syntax only; `gofmt` everything (CLAUDE.md §15).
- Stdlib `testing` only — no test libraries (CLAUDE.md §11).
- `doc.go` with a package comment for the new package (CLAUDE.md §8).
- No silent error discard (`_ = err`) (CLAUDE.md §15).
- Parameterized SQL only; no caller input concatenated into a statement (CLAUDE.md §13).
- **Do not commit** — commits only when the project owner asks (CLAUDE.md §16).
- `go build ./...`, `go vet ./...`, `go test ./...` must pass after every task.
- Run Go commands with `export PATH="$HOME/.local/go/bin:$PATH"` if `go` is not on PATH.

      `schema.sql` only runs on volume creation. Either recreate the volume
      (`docker compose down -v && docker compose up -d`, wipes local data) or run the

      `ALTER TABLE services ALTER COLUMN code SET GENERATED BY DEFAULT;`,
      `ALTER TABLE services ADD COLUMN IF NOT EXISTS active BOOLEAN NOT NULL DEFAULT TRUE;`,
      plus the `COMMENT ON COLUMN` and `CREATE INDEX ix_services_active` from `schema.sql`.
